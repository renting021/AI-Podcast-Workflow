# 播客质量检查清单

## 音频

- [ ] 文件存在且非空
- [ ] 格式可读取
- [ ] 时长合理
- [ ] 音频没有明显截断

## 转录

- [ ] 文件为 UTF-8
- [ ] 有时间戳
- [ ] 开头、中段、结尾均有内容
- [ ] 没有循环重复
- [ ] 说话人标签基本稳定

## 文章

- [ ] 章节严格保持播客时间顺序
- [ ] 覆盖主要主题和核心观点
- [ ] 覆盖反常识制度设计、组织机制案例和关键决策逻辑，而不只覆盖 shownotes 主线
- [ ] 嘉宾用具体例子解释原则时，保留“问题出现—内部追问—取舍判断—最终做法”的推理链
- [ ] 开头和结尾没有被遗漏
- [ ] 嘉宾背景、来源信息完整
- [ ] 关键观点均有原文依据
- [ ] 没有虚构事实、数字或引语
- [ ] 文章结构清晰，未过度压缩

## 对话现场感（访谈与圆桌必检）

- [ ] 已生成并锁定 `style_contract.json`
- [ ] 主持人的关键提问、追问和承接关系得到保留
- [ ] 无法确认具体嘉宾时使用角色标签，没有猜测姓名
- [ ] 每个非豁免访谈章节至少包含一个对话标签
- [ ] 连续同一说话人的自然发言已经合并为完整回答块，没有一句一标签造成阅读断裂
- [ ] 没有整章使用“主持人问到／嘉宾表示／节目讨论认为”替代问答
- [ ] 相邻分段接缝不存在对话体到第三方转述体的突变
- [ ] 分段重叠内容已去重，回答没有在边界处截断或遗漏
- [ ] `dialogue_quality.json.status` 为 `pass`

## 自迭代

- [ ] 每轮只重写检测失败的章节，没有无关全文漂移
- [ ] 每轮保留独立版本并追加 `revision_log.jsonl`
- [ ] 修订后重新检查时间、观点、证据和说话人归因
- [ ] 没有通过删除内容、降低阈值或虚构归因制造通过
- [ ] 连续两轮同一失败或三轮未通过时已经人工阻断
- [ ] 用户反馈已写入 `style_feedback.jsonl`，但未未经批准直接改写全局 Skill

## 发布

- [ ] 用户已确认最终稿
- [ ] 飞书目标文档唯一且正确
- [ ] 发布后前 20 行顺序一致
- [ ] 发布后全文长度与本地版本接近
- [ ] 返回文档链接和 `quality_report.json` 摘要

## 建议指标

- 时间覆盖：开头、中段、结尾均覆盖
- 主题覆盖：主要主题全部出现
- 证据覆盖：重要观点有原文片段
- 顺序一致：章节时间戳单调递增
- 对话密度：默认每 1000 个非空白字符不少于 0.45 个对话标签
- 对话信号占比：对话标签 ÷（对话标签 + 第三方归因信号）默认不少于 0.55
- 接缝漂移：上一章节合格而下一章节接近零对话密度时硬性报警
- 行数比例：仅作为异常报警，不作为唯一质量标准
