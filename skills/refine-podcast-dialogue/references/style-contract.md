# 对话体风格契约

版本：1.0.0

## 目标

保留访谈的提问、回应、追问、分歧、补充和现场推进，同时删除口吃、无信息语气词和机械重复。完整不等于逐字，精编不等于第三方摘要。

## 标签规则

优先使用：

```markdown
**主持人：** 问题……

**嘉宾：** 回答……
```

只有归因置信度高时才使用姓名：

```markdown
**主持人泓君：** 问题……

**Simon：** 回答……
```

多位嘉宾无法可靠区分时使用 `嘉宾`，不要猜测姓名。

## 允许的第三方叙述

以下位置可以使用短暂叙述：

- 章节开头交代背景；
- 解释听觉上发生但文字无法呈现的事件；
- 连接被剪除的寒暄或重复；
- 摘要、嘉宾介绍、来源和编辑说明。

叙述只能连接对话，不能连续取代整章问答。

## 禁止模式

不要把连续问答改成：

```text
主持人问到……嘉宾表示……Simon 进一步解释……节目讨论认为……
```

不要为了降低归因风险而删除主持人的问题。无法确认姓名时降低到角色标签，而不是改成会议纪要。

## 分段写作约束

- 以完整问答单元切分，不在回答中间截断；
- 相邻分段保留 60–120 秒重叠；
- 所有写作者读取同一合格样例；
- 每个访谈章节至少出现一个对话标签；
- 对话标签密度默认不少于每 1000 个非空白字符 0.45 个；
- 对话信号在“对话标签 + 第三方归因信号”中的占比默认不少于 0.55；
- 豁免章节不参与上述阈值。

阈值只用于发现异常，不能替代事实、归因和完整性审校。

## 合并检查

在每个分段接缝前后各检查至少一个完整问答单元。若上一节使用对话标签、下一节突然只有第三方转述，视为硬失败，而不是文风选择。
